# انتقال اجرای Evren Nexus به هاست

این بسته اجرای پروژه را روی همان هاست فعلی آماده می‌کند؛ هیچ Workflow فعلی را حذف یا غیرفعال نمی‌کند. فعلاً روی سایت اصلی اجرا نکنید و GitHub Actions را هم خاموش نکنید. ابتدا باید نسخه آزمایشی روی هاست بررسی شود.

## پیش‌نیازها
- Python 3 و Node.js نسخه 20 یا سازگار با اسکریپت‌های پروژه
- دسترسی نوشتن به checkout پروژه و document root سایت
- ابزار `flock`
- نصب یک‌باره وابستگی Node در ریشه checkout: `npm install --no-save cheerio@1.0.0-rc.12`

## راه‌اندازی آزمایشی
1. مخزن را خارج از `public_html` قرار دهید؛ مثلاً `/home/USERNAME/evrenexus`.
2. در ریشه checkout وابستگی را یک‌بار نصب کنید؛ نصب را داخل Cron تکرار نکنید.
3. فایل خصوصی `$HOME/.config/evrenexus/host.env` بسازید و مسیر واقعی سایت را در آن قرار دهید:
   `EVRENEXUS_WEBROOT=/home/USERNAME/public_html`
   مسیر بالا فقط نمونه است؛ مسیر واقعی هاست را وارد کنید. این فایل نباید وارد Git شود.
4. ابتدا فقط یک بار اجرا کنید:
   `bash hosting/run-update.sh news`
5. لاگ `$HOME/logs/evrenexus-update.log` را بررسی کنید و صفحه اصلی، آخرین مطالب، صفحات موضوعی، آرشیو مطالب مهم و قیمت‌ها را روی هاست باز کنید.
6. فقط پس از تأیید دستی، مسیرهای واقعی را در `hosting/crontab.example` جایگزین و Cronها را ثبت کنید.

## کارهایی که اجرا می‌شوند
- جمع‌آوری خبر و آزمون طبقه‌بندی، مگر اینکه اتوماسیون متوقف شده باشد.
- دریافت داده‌های TGJU و Nobitex، ساخت و اعتبارسنجی فید آخرین مطالب و ساخت داده‌های عمومی.
- بررسی تصویرها به‌صورت غیرمسدودکننده، همگام‌سازی فهرست مطالب و اجرای صریح سازنده صفحه‌های دائمی مقاله.
- به‌روزرسانی داده LBank و قیمت خودرو در حالت‌های جداگانه.
- انتشار فقط فایل‌های عمومیِ مشخص‌شده به document root. اسکریپت‌ها، فراداده Git، تنظیمات خصوصی و پایگاه خام خبرها کپی نمی‌شوند. فایل‌های مقصد که در checkout معادل ندارند حذف نمی‌شوند.

## محدودیت‌ها و ایمنی
این بسته به پنل هاست وصل نمی‌شود و Cron را از راه دور ثبت نمی‌کند. مرحله هوش مصنوعی `scripts/news_ai.py` عمداً خودکار اجرا نمی‌شود؛ Workflow فعلی AI نیز غیرفعال است و فعال‌سازی آن نیازمند تصمیم جداگانه، تنظیم کلیدها و آزمایش خروجی است. تا زمانی که خروجی نسخه هاست بررسی نشده، GitHub Actions فعال می‌ماند. در زمان مهاجرت نباید دو نسخه هم‌زمان منبع اصلی انتشار تلقی شوند.
